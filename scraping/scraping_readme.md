# Сбор данных - Krisha.kz

Скрапинг объявлений о продаже квартир с крупнейшей платформы недвижимости Казахстана.

## Стек

- `requests` - HTTP-запросы
- `BeautifulSoup` - парсинг HTML
- `pandas` - формирование датасета
- `re` - очистка данных через regex

## Процесс

**1. Сбор ссылок**  
Обход ~900 страниц листинга со случайными задержками (2–5 сек) для защиты от блокировки. Собрано ~19,000 URL, после дедупликации осталось **17,375 уникальных объявлений**.

> Дубликаты возникают из-за новых объявлений, которые сдвигают пагинацию во время сбора.

**2. Парсинг объявлений**  
Случайная выборка из 7,000 ссылок. С каждой страницы извлекается:

| Поле | Описание |
|---|---|
| `цена` | Цена в тенге |
| `комнаты` | Количество комнат |
| `город` | Город и район |
| `live.square` | Площадь квартиры |
| `flat.floor` | Этаж |
| `house.year` | Год постройки |
| `flat.building` | Тип дома |
| `map.complex` | Жилой комплекс |
| `описание` | Текстовое описание от продавца |
| + 10 доп. атрибутов | Балкон, санузел, ремонт, парковка и др. |

**3. Надёжность**  
- Auto-retry при ошибке 429 (бан) — пауза 60 сек и повтор
- Checkpoint-сохранение каждые 500 записей
- Полное логирование ошибок в отдельный файл

## Результат

- **7,000 объявлений**, 0 ошибок
- **26 признаков** на объявление (sparse — не все продавцы заполняют все поля)
- Сохранено в `krisha_final.csv`
